`strict: true` is the floor, not the ceiling. A few extra flags catch most of
the bugs I used to find in production.

## Flags worth turning on

- `noUncheckedIndexedAccess` — array and record access becomes `T | undefined`.
- `exactOptionalPropertyTypes` — `undefined` stops sneaking into optional keys.
- `noImplicitOverride` and `noFallthroughCasesInSwitch` — cheap correctness.

## The habit it forces

You stop guessing. If a value can be missing, the types say so, and you handle
it at the edge instead of at the crash.

```ts
const first = items[0];
if (!first) return; // now required, and now obvious
```
