A small Python CLI for the boring parts of PDF wrangling.

## Commands

```sh
pdftk merge ./slides/*.pdf -o lecture.pdf
pdftk split lecture.pdf --every 20
pdftk stamp lecture.pdf --text "DRAFT"
```

Wraps proven libraries with sane defaults and dry-run support.
