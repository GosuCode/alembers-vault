The site you are reading: a content-first static archive for tech blogs, past
question papers, and the projects I built through my BCA.

## Highlights

- **Astro** static output — pages pre-rendered at build time, zero JS by default.
- **React islands** only where needed (PDF viewer, search and filters).
- **Supabase** for stored documents — Postgres metadata plus a public storage bucket.
- **OCR pipeline** that makes scanned past papers searchable by their text.
- **Cloudflare Workers** hosting with a custom domain.

## How it is put together

| Layer    | Choice                          |
| -------- | ------------------------------- |
| Frontend | Astro + React islands           |
| Styling  | Tailwind CSS v4                 |
| Data     | Supabase (Postgres + Storage)   |
| Search   | Build-time rendering + JSON-LD  |
| Hosting  | Cloudflare Workers (static)     |

Academic documents are uploaded with a small script and listed on `/academic/`;
each paper also gets its own indexable page.
